## Guidelines for New ADRs

- **Make a decision**, not document it post-hoc. Add a new record when you've made a significant architectural choice.
- Use the format in [ADR 0001](./0001-record-architecture-decisions.md): Status / Context / Decision / Consequences.
- Keep it plain Markdown with no external links; summarize what a link would contain.
- To supersede an earlier decision, create a new ADR and flip the old one's status to `Superseded`.
